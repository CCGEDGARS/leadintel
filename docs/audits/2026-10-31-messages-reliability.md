## Failure handling, provenance and investigation

Failures remain distinguishable: invalid or incomplete input; unsupported factual evidence; unavailable provider/connection; canceled or timed-out work; superseded account/recipient/source context; revision/sync conflict; local recovery without confirmed cloud persistence; and submitted/uncertain delivery requiring reconciliation. A missing result is not success. A configured provider is not an execution receipt. Unknown outcomes are not silently retried as though nothing happened.

The seller scrape receipt fix retains actual successful-read flags and timestamps across Profile normalization into message evidence. The shared brief keeps source quotes/URLs/dates, selected-role status, commercial hypotheses and gaps separate. Writing guidance attribution follows exact text plus matching HTML and source/skill revisions through Apply, Undo and save/reload. Translation stores its source/translator/reviewer/language-pack authority separately; these fields do not establish native review.

`LeadIntelReliabilityTrace` / `LeadIntelSetupTrace` version `20261031-messages-v1` extends the bounded existing buffer and emits `leadintel:messages-operation`. The actual wired `message_save` operation records safe IDs, stage/action/phase/outcome/workspace/time, including pending/failed/stale persistence. The buffer holds at most 100 copied records and clears on account/context invalidation. It contains no draft, recipient address, source passage or credential. The action allowlist also supports message generation/translation/reopen/approval/delivery; an allowlisted action is not proof that every path emits it.

Investigate an incident by comparing the safe operation/context ID with existing backend audits, CRM script/activity revisions, source/provider execution receipts, idempotency/queue/receipt records and the original approved recipient snapshot. Preserve both conflict versions and uncertain-submission evidence. No numeric latency/error/yield baseline, production alarm delivery, new monitoring platform or SLA has been demonstrated.
