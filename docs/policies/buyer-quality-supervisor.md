## One quality assessment for both flows

`buyerQualityAssessment` in the shared discovery engine checks current mandatory research, independent AI review, four qualified priority buyers, buying committee coverage and the target of two confirmed priority work emails. It computes status from retained evidence and live contact-policy acceptance, never from an overall model opinion. Passing research does not guarantee addresses exist. Research coverage requires the current policy version, fresh successful official/public/phone/LinkedIn checks for every retained identity, the required priority deep wave, completed accountability and a read official page. ## AI supervisor

The existing workspace evidence-review service (Gemini first, then configured active AI and OpenAI fallbacks within one 45-second review deadline) reviews supplied sources, every retained identity, current roles, published addresses and mandatory-check coverage. It has no web access and cannot create verified contacts, claim tool execution or approve spending. Its response must identify every reviewed person. Missing identities, unavailable or malformed reviews, changed identity/role/email inputs and material evidence gaps prevent a supervised pass. Findings cite an existing input person and supplied source URL. Current conflicts still block the existing qualification and selection gates.

Manual research and the approved automatic workflow call the same review service and save a bounded report with provider, time, input signature, reviewed IDs, conflicts and sourced findings. Normalization and CRM snapshots preserve it. The UI reports unavailable/not assessed honestly. An unavailable supervisor stops selection of a new automatic recipient; already accepted saved contacts remain reusable under existing evidence gates.

The review deadline is enforced even when an upstream operation ignores cancellation or the endpoint supplies a non-expiring request signal. A slow primary reviewer has at most 40% of the review budget (capped at 20 seconds), preserving time for fallback; the browser response timeout is 50 seconds, including a five-second settlement buffer. Both flows use the shared compact evidence builder: one focused passage per retained person first, then additional context, at most 20 passages and 20,000 excerpt characters. Structured review uses low reasoning effort in the existing OpenAI adapter. Provider failure reasons are retained without credentials. Full ranking/quality assessment runs once per company render; per-card coverage checks use the shared lightweight coverage predicate.

The main journey includes a mandatory Buyers quality requirement, separate from identifying names. Page-level readiness shows Needs review when the quality goal is unmet. These presentation checks do not revoke a source-confirmed contact or block an explicitly selected manual recipient merely because another research requirement remains pending.
