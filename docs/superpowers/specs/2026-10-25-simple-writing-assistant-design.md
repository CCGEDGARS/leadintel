# Simple Writing Assistant — approved conversation design

The user approved removing Shorten, Strengthen persuasion, Personalize, Draft length and the separate Ask assistant action. Keep the editable working draft on the left; on the right show one outcome instruction, three optional books and one main Preview changes action. The same field handles drafting, edits and questions. Questions return advice without silently replacing the draft. Book activation alone never generates content; zero, one, two or three books may be used. Keep activation session-only and show the active count clearly.

Apply changes accepts an AI preview into the assistant working copy only. Save draft persists the exact customer copy to LeadIntel and updates Messages, or saves independent general writing to its own library. Save as template creates a reusable copy through the existing named template workflow. Keep Preview changes separate from Apply changes and Save draft. Keep Undo, formatting, original recovery, script loading and library management. Preserve protected masters, sender/recipient, links, source citations, evidence checks, workspace isolation, scope guards and channel-specific storage. No sending or approval authority is added.

The chosen approach reuses the existing workbench/controller, reference retrieval and storage adapters. A visible preset toolbar was rejected because it competes with free-form outcomes. Multiple separate advice/edit modes were rejected because the single field can express intent. The backend receives an explicit auto intent, lets the model return advice or a complete proposed working draft, and validates the response using existing evidence and identity rules. Old preview/advice requests and stored length preferences remain compatible, while the simplified UI sends no hidden length preference.

Save draft stays open with a clear success or retry message. A false or failed save never reports success. Pending previews must be applied or discarded before saving, so the saved copy is unambiguous. Clear stale save acknowledgments when the working text changes. The layout gives the editor about 60% of desktop space, places instructions above the three book cards, and keeps results readable on compact screens.
