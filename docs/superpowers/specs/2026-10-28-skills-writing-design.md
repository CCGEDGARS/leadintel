# Skills-first Writing Assistant

Approved in the 28 October discussion: retain the two-column working-draft/instructions modal. Put all saved skills in a bounded scrollable list, permit up to three Ready enabled selections, show selected chips and compact cover thumbnails when available. Selections persist for this open working-copy session and reset at existing context/session boundaries. Instructions are optional for existing text; empty text requires a topic/instruction. Improve draft generates and validates a working alternative, updates the left editor immediately, retains Undo and provenance, never saves/approves/sends. Repeat operates on current text, with no forced cosmetic rewrite. General writing excludes customer context.

Books are collapsed knowledge sources. Select one to ask an advisory question using the current context; answers do not mutate the draft. Writing requests use skill references, not selected discussion books. Book requests exclude skill references. Retain citations, scoped history and stale-response protection. Management remains in Content Library; skills survive source deletion.

Approaches considered: separate library-first experience; large book cards alongside duplicate skill selection; retain existing modal with skills first and books collapsed. User selected the final approach to reduce cognitive load. Existing preview APIs remain for other callers. The main button owns the new validated direct-update workflow. Source-based text discussion uses the existing authenticated retrieval API. Voice is a separate integration, not represented as available in this change.
