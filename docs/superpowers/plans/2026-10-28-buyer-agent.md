# Buyer Agent — approved design and implementation plan

Approved in the product discussion and authorized by “do it”, 28 October 2026.

Buyer Agent is the evidence-acquisition and checking workflow in Buyers. It reuses the source-backed company brief and selected company development, seller offer and existing contacts. Public identity/employer/role and industry/event/project searches run within existing limits, with their own execution receipts. Exact professional profiles identify different people; a shared name cannot merge different employers. Project geography never changes the company identity.

The existing independent AI supervisor receives the same brief, trigger, employer and exact profiles. It reviews evidence rather than certifying provider confidence. Identity, opportunity responsibility, search completion and contact availability remain separate; unknown responsibility remains provisional. Existing paid lookup approvals, source confirmation, workspace guards and send controls remain authoritative. Reopening saved research does not start another run.

1. Add shared context, bounded targeted queries, evidence assessment, serialization and quality requirements.
2. Connect manual and approved automatic flows and independent reviewer.
3. Add compact Buyer Agent panel and Recheck action using existing request/cancellation controls.
4. Verify same-name/profile separation, geography, cross-customer context, search failures/cache, save/reload and CRM preservation; run customer/backend suites and build.
5. Publish reviewed code and require exact-SHA release proof before claiming production completion.
