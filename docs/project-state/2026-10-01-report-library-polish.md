# Report library polish

Reviewed actual customer screenshots: saved reports were raw browser buttons with ISO evidence timestamps that obscured distinct retry snapshots. Delete used an unstyled browser OK prompt.

Added styled responsive report cards, local readable saved dates distinct from evidence dates, partial/complete badges, explicit View and Delete actions, quieter bulk deletion, and a matching accessible native dialog with descriptive title and Keep/Delete buttons. Keep is focused by default; Escape cancels; opening confirmation does not mutate state. Only explicit confirmation removes snapshot history. Existing Strategy evidence preservation and deletion marker remain.
