# Website monitoring visibility

The existing website monitoring module was hidden until strategy activation, placed near the bottom of Strategy and kept website entry, alerts and history inside Advanced settings. This made an important recurring research tool hard to discover.

The highlighted Website monitoring panel now sits above customer profiles in Strategy, is visible before activation and opens by default. Website entry, frequency, depth, alert threshold, Save, Run now, alerts and history are directly accessible. Only detailed source-category and signal choices remain collapsed. The summary identifies Setup required, Off or Active with the saved frequency. Activation and authenticated save/run requirements remain in force; visibility does not enable monitoring or start paid research.

Existing input IDs, workspace persistence, API routes, scheduling and alert records are reused. Verification covers DOM placement/disclosure and unique controls, existing activation gates, the customer suite, static build and exact-SHA production release proof. No new scheduled run or authenticated customer acceptance is implied by these UI checks.
