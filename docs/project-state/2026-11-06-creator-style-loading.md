# Creator masters load from style buttons

Owner instruction: selecting a style must load its saved Creator Library reference in Email, LinkedIn and Phone.

Managed style selection is an explicit working-copy replacement and now needs one click. Existing editor/phone history retains Undo; it does not save, approve or send. Initial catalogue loading is awaited rather than requiring a second click. Competing clicks use the latest selection and reject a changed buyer/channel scope. Creator provenance takes precedence over built-in equality flags, including the special Storyselling renderer, so owner masters cannot route back to bundled text.

Validation covers all 15 channel/style button combinations, the real email and LinkedIn adapters for all five styles and Undo, early and competing clicks, missing masters, phone separation/save/reopen and source persistence. Templates use the existing declared-field renderer; bracketed notes remain visible and are not automatically researched or resolved. Four-stage InMail is a separate existing workflow and is not changed by this direct-message style update.

Production proof and authenticated customer-session acceptance are reported separately. No live customer script records are edited by this change.
