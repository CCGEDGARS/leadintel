Industry-specific signals still provide industrial context where appropriate.

Signal candidates, actual query markets and preview themes adapt; renaming the seller to Ercon or another name does not change signal selection. Full 1,318 customer tests and static build pass, including existing reference activation, known-company import and workspace isolation coverage. This establishes tested portability boundaries, not a claim that every possible industry has live customer acceptance. Production completion requires exact-SHA CI and release-integrity proof. No paid research was started.
