# Messages: style application, language originals and translation review

Core styles stay protected. Selecting a style does not rewrite the message: Create message / Apply selected style performs the explicit generation. Saved personal templates remain in My Templates. The English original supplies factual meaning; translated versions are editable independent copies. English changes mark copies stale, and previous translated copies can be restored.

Original scripts is inside the core template panel. English displays the protected master; other languages start empty. The workspace owner can Save & lock an approved original, deliberately unlock it, or restore a previous revision. Records are isolated by workspace, channel, style and language. LinkedIn excludes Brutal Honesty. Server writes enforce ownership, lock transitions and append-only revision history. Pending transitions must sync successfully before another transition; failed synchronization exposes Retry original sync. Campaign/workspace resets preserve protected originals. Concurrent project state writes use a mandatory version and database CAS.

Translation uses the existing configured AI provider. A matching locked language original supplies voice only, never its example facts. The initial translation and separate editorial review both receive English meaning, protected names and native-language guidance. Deterministic integrity checks reject changes to figures, currencies, links and placeholders. Changes to the source or captured language reference during a request discard its result. Saved versions record the reference revision and editorial-review completion. This is a quality workflow, not a guarantee of perfect translation; owner-approved Latvian originals still need to be supplied.

Researched facts appear as concise source cards with date, source link and an explicit review action. Recommendations remain unverified until the existing confirmation gate. Candidate cleaning and saved-source validation share the same canonical extraction; unrelated third-party sources are filtered, duplicate source URLs and identifiable bilingual project copies collapse, and background stays separate.

Validation: full customer suite, backend suite, build, targeted synchronization/revision/reference-drift/provenance regressions. Production and authenticated UI evidence are recorded separately after exact-release verification. No outreach is sent by these changes.
