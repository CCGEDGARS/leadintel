## Confirmed defects and fixes

1. **Completed provider evidence was discarded when its peer stalled.** `runMarketResearch` launched OpenAI and Firecrawl together but merged/saved their results only after `Promise.all` settled. If one returned sources and its peer remained pending until the overall deadline, cancellation bypassed that merge. A controlled test of the shipping functions reproduced a complete Firecrawl receipt with one result, an empty saved result list, error status, and the generic Gemini cleanup message. Each successful provider now merges and saves its own checkpoint immediately, outside the OpenAI retry operation. No additional provider request is introduced.
2. **Completed page reads had the same batch boundary problem.** Each successful extraction now saves independently before other reads finish. A stalled second read cannot erase the first completed page.
3. **A shorter extracted body could lose to a longer search summary.** Merge now prefers nonempty extracted source text over unextracted snippets in either input order. Subsequent snippets cannot replace extracted text. Existing richer extracted evidence, verification verdicts, publication metadata, and source-provider provenance are retained. Empty legacy extraction rows cannot block usable snippets or falsely label the replacement as extracted.
4. **The original stop reason was missing.** Interruption records the bounded run reason first in saved errors, so the visible details include the deadline/cancellation reason. Provider outcomes derive from actual receipts. Error details open automatically on failed runs.
5. **Zero-source error reports were labeled partial.** Saved history now says “Research failed,” and the exported/viewed report explicitly states that no usable evidence was saved. This is independent of the provider issue.

Existing workspace/account/Strategy/run guards remain on every checkpoint. Late callbacks cannot save into changed context. Source count does not establish verification, commercial fit, or buying intent; incomplete research remains partial and failed verification remains visible.
