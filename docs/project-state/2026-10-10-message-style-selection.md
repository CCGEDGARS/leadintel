# Explicit message style selection — 10 October 2026

Root cause: email style changes used the automatic/background preparation path. Its deliberate saved/manual/approved/translation safeguards proposed an update instead of applying it, so NLP could be selected while Professional remained in the working editor. Selecting a library template also retained the prior default snapshot, which could override the explicit choice on Update.

User-authorized fix: a deliberate style/template selection invokes controlled template restoration with the selected pattern, its supported subject and current facts. The previous working text remains available through persistent Undo and CRM serialization. Approval is invalidated and Save is required again. Background refreshes retain their existing protections; core originals remain verbatim. Other language versions remain recoverable and become stale against the new English source. Field preparation cancels prior requests and rejects changed style/workspace/recipient/draft context. Event invitations and AI Original retain their separate actions.

Coverage reproduces the old mismatch through the production selector handler and verifies the visible NLP button/editor, saved/manual/approved/translated copies, CRM reload/Undo, and late field-response isolation. Cache changes apply to the Discovery entry and Outreach module. Exact-SHA CI, manifest, backend health and all mandatory release checks are required before claiming production success. Tests/release verification do not establish authenticated customer acceptance or authorize sending.
