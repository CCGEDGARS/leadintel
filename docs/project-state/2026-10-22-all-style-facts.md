# All-style factual preparation — 22 October 2026

The owner requested the shared preparation rule for all styles after an NLP draft exposed missing project, milestone and opening-year fields.

## Root causes and change

The old subject-only checkpoint could skip mandatory body facts. Research planning assumed a recognized project before searching for a real one. Evidence arrived after an explicit template action without completing its untouched draft. Missing fields still received an applied/ready banner, and scope did not include the factual preparation outcome.

The shared preparation report now retains buyer and seller facts, missing fields, source references and the raw reviewed event. All email styles use bounded official research with per-query receipts and actual provider execution outcomes. Specific mandatory seller gaps receive their own plan even if generic evidence is complete. Recipient/Profile ownership bounds reuse. AI Generated waits for preflight; deterministic styles show Preparing while their safe factual fallback is completed. Missing project-opening atoms use the owner-approved existing no-event omission. Other unresolved markers show Needs information and block flow/approval. Saved status remains separate.

The asynchronous completion rechecks workspace, recipient, selected style and exact draft. It preserves the original explicit action's Undo target. A cancelled request cannot start a fallback search. Reopening retains exact saved/manual text, evidence and research receipts. Schedule outcome changes invalidate untouched automatic preparation scopes. Approved source masters are unchanged.
