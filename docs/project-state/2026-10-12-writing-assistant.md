# Integrated Writing Assistant

Replaces the Step 6 Adjust message card. Shorten, Rewrite and Reset retain their direct actions. Chat has current buyer, company, reviewed seller facts, trigger, style/language and exact unsaved draft context. Chat proposals use Apply/Discard; applying invalidates approval and saved readiness, preserves the first tailored original and recovery, and stores source provenance in the existing CRM script metadata. Save remains explicit. No sending, automatic approvals or built-in skills are added.

The sole existing private source library moves into Sources and survives compact/expanded switching. PDF/TXT/Markdown limits and extraction/analysis remain unchanged. Source roles (guidance/seller/customer) persist with revision guards through migration 0032. A question may use all active sources or one specific active source. Deterministic lexical retrieval uses at most eight page/line-aware passages and 12,000 characters shared with selected source instructions and relevant learned techniques. Partial/unavailable/no-match coverage is disclosed. Retrieved material is untrusted and document claims remain attributed input, not independent verification.

A dedicated membership-protected endpoint reuses workspace AI credentials, provider credit recovery/failure reporting and usage accounting. Server-owned rules bound context and history, validate structured replies, URLs/identities/numbers/meeting duration/disclosure and retrieved citation IDs, and recheck source revision after generation. Client ownership checks reject changed recipient, workspace, channel, evidence, style, language, draft or sources. Apply additionally refreshes the source library and rechecks context before modifying the working message.

Conversation is transient. Uploaded originals/extracted documents and explicitly saved drafts retain existing durable storage. The expanded view relocates the same panel, source instance and controls; model/document/user text is rendered safely. Ask LeadIntel remains separate with its existing upload policy. Canonical approved-reference-scripts.js is byte-identical to the base commit.

Limitations: lexical retrieval depends on matching words and readable extracted text; no OCR or semantic vector search. Automated invariants cannot establish arbitrary semantic truth. Users must review generated factual claims and confirm unsupported information through existing evidence workflows. Existing quick-action generation remains separate from chat and uses its original validation. Built-in writing skills are deferred.

Verification evidence is recorded in the implementation ledger and release PR. Production status requires exact-SHA CI, matching release manifests/backend health and the machine-readable mandatory release proof; no successful local build alone constitutes production proof.
