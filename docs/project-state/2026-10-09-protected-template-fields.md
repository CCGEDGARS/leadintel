# Protected originals and grammatical personalization

Root cause: deterministic personalization copied full seller Profile fields and raw reviewed research directly into grammatical slots. A company sentence could follow “could”, yielding “could ERCON can”; a Swedish excerpt could appear inside an English email; multiple capability lists could form long repetitive paragraphs.

Complex or foreign source fields now go through a bounded English field-preparation request. The AI receives source data and six field definitions, never authority to replace the whole approved template. The client rejects extra keys, incomplete/overlong fields, foreign text patterns, links/placeholders/markup, unsupported numbers, empty-source inventions and benefits containing a company subject or modal verb. The protected template assembles validated fields deterministically. The approved verbatim reference scripts and protected core template bodies are unchanged. Seller/company facts still come from the active workspace and reviewed evidence only. Numeric/structural validation does not independently prove every semantic paraphrase; human review remains required.

Prepared fields retain their exact source fingerprint in CRM draft metadata. Changed workspace/buyer/channel/seller/evidence or intervening manual edits prevent a late response from applying. Existing drafts are never replaced by render, reload or buyer selection. Explicit template application starts preparation when required; failure leaves the working text intact and explains retry. Corrected originals use a new context version; earlier original snapshots are retained in history. Applying another version with the same context cannot overwrite the protected first tailored original. Manual Edit and accepted Rewrite change the working draft only. Existing owner-only unlock/save-and-lock original management and server revision/history guards remain in force.

Tests reproduce the screenshot with Swedish evidence and sentence-shaped benefit fields across all four styles; reject attempted whole-message/template AI outputs and invented numbers/links; verify exact protected master/original preservation, CRM save/reload, original history and late-response rejection after buyer changes or manual edits. Customer suite, static build, exact-SHA CI and production proof are required. No outreach is sent and no authenticated customer account or external AI result is claimed by automated tests.
