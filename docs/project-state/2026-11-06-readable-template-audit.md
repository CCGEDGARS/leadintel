# Readable template personalization audit

The owner NLP script used labels such as `[Your full name]` and `[Your LinkedIn profile URL]`, while the library recognized only shorter aliases. Project and seller atoms existed in the Messages fact pipeline but were not mapped to the readable script vocabulary. A button-routing test with simplified masters did not establish personalization coverage for actual owner labels.

The channel library now recognizes the supplied identity, project, company, experience, service, reference and meeting labels. Its values use the existing reviewed fact audit, sender identity, approved answers and same-domain extracted seller evidence. Word-form experience such as “more than thirty years” is accepted without converting it to an invented date or number. Existing curly-token values and phone context remain compatible.

Unsupported story participants/outcomes, named references, comparative claims, commitments and missing links remain unresolved. A capability page does not become a completed customer story. Contradictory or past project years rejected by the fact audit remain rejected. Other sellers’ sources and unreviewed triggers cannot fill the slots. Master literals and formatting are preserved; explicit style application produces a working draft and retains existing save/Undo behavior.

Validation includes the owner NLP label structure across all three channels, rich text, source isolation, conflicting years, word-form experience, and authenticated owner-library style selection through exact CRM save and fresh browser reopen. The actual account’s current private registry and saved evidence were not accessible during this audit; controlled tests are not a claim that those records were modified.

Separate official-page research on 6 November found ERCON’s published team experience and capabilities and Viscaria’s 4 November loading-hall progress update. The user received a sourced working-copy artifact. No customer-specific source text or defaults are added to shared runtime code, and no outreach is sent.

Combined-context follow-up: missing message offer/difference/proof/approach now fall back to the corresponding accepted or user-supplied Profile answers. Explicit message details retain precedence. Approved references no longer require duplicate entry into message settings. Relevant service/work packages preserve the supplied service description instead of collapsing it to a material such as “steel”. A fifteen-combination channel/style regression verifies accepted Profile facts, extracted seller website experience and the reviewed buyer development in one working script, including a software-industry fixture and unchanged masters. Unaccepted Profile suggestions remain excluded. Publication remains blocked by automatic approval review; this local acceptance is not a live-account update.
