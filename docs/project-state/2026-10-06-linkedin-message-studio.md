# LinkedIn message studio — 6 October 2026

Approved flow: Buyers → Confirm LinkedIn → review identity → Proceed to message → Step 6 in LinkedIn mode. Only an empty buyer draft requests automatic generation. Approved Step 2 sender information remains mandatory; missing inputs show a precise explanation instead of invented claims. Reopening an edited draft never regenerates it automatically. Explicit Generate and Improve remain available.

LinkedIn has AI Generated and three independent numbered body-only personal templates. No email subject choices or protected email core editors appear in this channel. Save as template converts recipient and sender details to reusable fields, offers AI preparation, requires review, and supports edit/rename, explicit replacement, delete and undo. The five existing email slots and email writing choice remain separate. Shared facts derive from the active workspace; unsupported events, years, numeric results and professions are never defaults. Generated messages are limited to 1,200 characters and retain the 30-minute Zoom / Calendly action.

Buyer drafts are cached by company, buyer identity and channel. Channel/buyer switches remember the previous draft. Reopening also searches paginated canonical CRM history for the exact buyer and LinkedIn channel. AI output and user edits remain editable; successful generation saves a CRM script snapshot. Save draft to CRM also gives visible success/failure feedback. Workspace sync treats individual LinkedIn slots and buyer draft records atomically, avoiding mixed names/bodies from competing edits.

Copy message and Open LinkedIn profile support manual sending only. The user must affirm that they sent the message before Record as sent in CRM is enabled. This writes the idempotent contact.linkedin_message_sent activity, exact buyer/message snapshot, manual/channel metadata and Contacted stage. It does not call a LinkedIn or email sending service. Tests exercise real CRM route storage, duplicate protection, no email.sent activity, explicit acknowledgment and late-response edit preservation. Customer UI verification must never falsely record a message as sent.
