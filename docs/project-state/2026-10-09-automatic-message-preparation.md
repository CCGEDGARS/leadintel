# Automatic message preparation — 9 October 2026

## Agreed behaviour

A selected, verified strongest company signal automatically prepares the five approved subject options and an email using the selected approved style. There is no additional mandatory Apply step. Protected original wording, factual slot restrictions, the 20-minute invitation and original word limits stay in force. Rewrite remains an explicit action. Script preparation never saves, approves or sends outreach.

## Connected paths

Preparation runs after the confirmed email buyer handoff, module reopening, verified official signal selection, third-party source confirmation, style changes and saved sender/settings updates. Explicit research may update an automatically selected official source; a manually reviewed selection is retained. Official evidence uses the exact extracted event sentence, including events beyond the first 900 page characters. Unreviewed third-party sources still require confirmation. A matching completed scope or existing proposal prevents repeat preparation on reopening. Required seller confirmation and the exact workspace/recipient handoff remain gates.

Untouched controlled drafts update automatically. Edited, saved, approved, rewritten, legacy unknown and translated messages are preserved; preparation produces an Updated version ready panel. Use updated version explicitly accepts it; Keep current message discards it. Pending changes remain blocked from approval until the selected context and message are reconciled. Previous working text and original snapshots survive acceptance. Proposals and Save intent markers persist inside the existing CRM script snapshot. Source provenance for the applied message is retained separately from a proposed new source.

AI is limited to bounded factual fields when necessary, with the existing 45-second abort, source fingerprint, immutable assembly and word limits. Delayed results cannot cross draft edits, source/style changes, cancellation, buyer handoffs or workspace changes. AI Generated and optional event campaigns retain their deliberate generation controls. Protected English originals and the existing saved translation workflow remain intact.

## Related recurring defect

NLP, Friendly and Brutal subjects previously tried to insert whole research sentences into compact subject fields. They now share the verified compact project extraction already used by Professional, and NLP delivery wording derives from the current approved seller services. Five approved patterns per style remain unchanged; genuinely unsupported slots stay unavailable. No reference customer facts become runtime defaults.
