# Professional master enforcement

User supplied the approved Professional master alongside an incorrect generated email. The master stored in approved-reference-scripts.js was already correct. The alternate Professional default in message-studio.js used a different opening, role question, paragraph structure, focus line and invitation. The protected assembler additionally treated fixed focus/goal/meeting-purpose wording as profile fact slots. That let long value propositions replace agreed wording. Previously cached working messages could also remain while field preparation failed. Source code alone cannot establish the exact saved customer draft's provenance.

Professional now derives its working pattern directly from the approved paragraph record. Literal master paragraphs are not modified. Only recipient, sender identity, supported experience, current services, reviewed development/project, industry terms and exact links are variable. Quality/cost/delivery focus, role question, 20-minute invitation, goal framing, comparison purpose and closing structure stay fixed. First name remains the sign-off.

Production/project terminology follows confirmed seller context; unrelated professions do not inherit manufacturing experience or Ercon defaults. Experience is sourced from an actual experience sentence, not a capabilities list or certifications. Unused profile value, delivery-approach and meeting-purpose fields cannot enter the fixed Professional body or trigger needless preparation. Professional event sentences are converted into a noun phrase for I noticed. A missing reference link retains [link] and existing approval validation blocks unresolved placeholders.

Contract version advances to verbatim-facts-v4 and tailoringVersion 4 to invalidate old prepared caches and tailored-original keys. Previous originals and manual/saved drafts remain protected; corrected output is proposed for review rather than silently replacing intentional text. Legacy untouched controlled drafts can update automatically. Existing approval guard rejects older controlled template versions. The editor now names the style of the displayed email; a failed switch to NLP explicitly says NLP has not been applied instead of claiming it is still preparing.

Regression includes exact equality with the user-pasted master after factual identity/link substitutions, deliberately oversized unused profile fields, immutable original paragraphs, fixed clauses under AI-prepared profile output, cross-industry context, missing reference links, and existing manual/edit/rewrite/CRM persistence tests.

Release proof covers exact published SHA, CI, health and mandatory smokes. It does not prove successful AI field preparation or replacement of a signed-in customer's saved draft.
