# Mandatory page procedures — 2026-10-10

The user authorized ownership of a reliable, practical page-opening process and internal quality control consistent with the previous message, buyer, CRM and template agreements.

## Cause and implementation

The pages had authoritative individual gates, but no shared current-input readiness record or consistent user guidance. A previously enabled control could outlive a context change, and delayed CRM buyer search or provider send responses could continue against a mutated workspace bridge.

Added the shared in-memory page coordinator, compact expandable status UI and action-scoped page adapters for Setup, Profile, Strategy, Companies, Buyers, Messages, Delivery and CRM. The coordinator checks current workspace/loading/sync, reuses canonical validation, performs only registered existing opening preparation, and rechecks actual results. Critical actions read fresh inputs. Opening failures remain blocked until a successful reopening. Missing readiness engine assets block critical UI controls while editing remains available.

Messages retain their existing evidence-first preparation and immutable core contract. Controlled English templates are checked against current deterministic assembly. Unverified selected triggers, stale event semantic details, changed sender/settings, unresolved placeholders and unsaved flow/library content fail their relevant action gates. Deliberate manual, personal, rewritten and translated content remains under its own authority. Existing saved-draft preservation, update proposals, first original, Undo, Save, event precedence and default-template snapshot rules remain intact.

Manual send tickets compare complete private context before the provider request and before recording the response. If a provider confirms a send after context changes, the app reports the need to review it in the original workspace and cannot save into the new workspace. CRM clears prior workspace records and checks captured workspace/selection before saving delayed buyer-search results.

No schema, backend provider, scheduled worker, extra AI quality agent, automatic research, automatic approval or automatic sending was added. The audit stores up to thirty check receipts in memory without message/contact/source content. Full contract: `docs/policies/mandatory-page-procedures.md`.
