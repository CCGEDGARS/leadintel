# Shared Buyers and Messages brief

The owner approved making one source-backed brief mandatory after the earlier missing-field fallback removed all buyer context. The preceding release prevented unsupported claims but produced a generic NLP introduction even though construction in Boden was known.

The root handoff problem was that Buyers held a reconciled company dossier, while Messages rebuilt a smaller opportunity dossier from candidate evidence only. The dossier's full verified quotes were not a dedicated personalization input.

The shared brief now derives bounded official facts, developments, source URLs/dates, selected-buyer role status, hypotheses and gaps. Buyers shows it above contact cards. Outreach preserves it and merges its quotes into source evidence; cached recipients update context while retaining exact working text. Relevant extracted developments rank above old generic items. AI and personal templates receive the same facts. Core project-opening styles use the expressly approved factual observation when the full milestone/year frame is incomplete. Masters remain unchanged, and no communication is sent by these actions.
